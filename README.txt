SHRIYA ENTERPRISES — SIMPLE HTML WEBSITE
=======================================

OPEN THE WEBSITE
----------------
1. Extract/unzip this folder.
2. Double-click index.html.
3. The website opens in your browser. No installation or internet is required for the design and photo.

OPEN IN VS CODE
---------------
1. Open VS Code.
2. Click File > Open Folder and select this extracted folder.
3. Open index.html to edit the website.
4. To preview, right-click index.html in VS Code and choose "Reveal in File Explorer" (Windows) or "Reveal in Finder" (Mac), then double-click it.

There is no npm install, npm run dev, package.json, React, or node_modules in this version.

CHANGE YOUR MOBILE NUMBER
-------------------------
In VS Code, open index.html and use Edit > Replace:
- Replace +91 98765 43210 with the number you want visitors to see.
- Replace +919876543210 in the tel: link with your number, including country code and no spaces.
- Replace 919876543210 in the wa.me link with your WhatsApp number, including country code and no spaces.

CHANGE ADDRESS OR OPENING HOURS
-------------------------------
Open index.html and use Edit > Find to search for the current address or hours, then replace the text.

IMPORTANT
---------
The phone number, address, opening hours, and expanded service list are sample details. Replace them with your real business information before publishing.
